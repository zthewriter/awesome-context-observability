## [1.0.0] - 2026-10-18

The first tagged release.

### Added

- The list: answer and passage analytics, docs platforms with AI insights, AI
  search visibility, AI agent and crawler traffic, retrieval tracing, standards
  and specs, and learning resources.
- A "Measuring delivered context" learning resource that points to the
  cookbook's observe recipe.
- A correction form, beside the broken-entry form.
- `SECURITY.md`, `CITATION.cff`, `VERSIONING.md`, a markdownlint check in CI, and
  vendor-neutral and verified-figures items in the pull request checklist.

### Changed

- Both author-maintained learning resources carry a disclosure.
